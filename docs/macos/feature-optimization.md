# 用量日历与趋势悬浮卡优化

日期：2026-09-16。

原悬浮卡直接展开所有模型，卡片高度随模型数量增长；趋势提示随最近曲线切换为模型用量，难以快速查看总量。

现在日历与趋势共用 `DailyUsageHoverCard`，总 Token 使用大字号，保留四类 Token 和等值费用摘要。模型明细默认折叠，点击展开后保持卡片显示，支持滚动阅读；收起后恢复悬浮关闭行为。趋势按鼠标横向位置选择日期，高亮并锚定该日期最高的可见节点，忽略鼠标纵向距离；总量曲线隐藏时使用最高可见模型节点，卡片使用对应日期或周期的完整汇总数据。关闭卡片、切换月份或隐藏曲线会清理展开状态。

验证：完整 XCTest 套件通过，覆盖鼠标纵向移动、横向切换日期、隐藏总量、日期中点以及零值重合节点优先总量；项目脚本 `./script/build_and_run.sh --verify` 构建、启动并核实当前工作区 App 进程通过。Universal Release 构建通过，产物版本为 1.7.0（Build 12），支持 arm64 与 x86_64。已重新导出 54 张文档截图，并检查趋势卡片的折叠、展开明细以及日历悬浮效果；`git diff --check` 通过。

## 菜单栏弹窗布局（2026-09-20）

原布局把今日 Token 构成放在额度摘要与额度曲线之间，更新区域另设卡片，垂直层级过多。现在将套餐、额度余额、重置提示和近 7 天曲线归于同一卡片；今日 Token 总量和四类构成放在下一张紧凑卡片。更新提示简化为一行，当前版本保留在悬停提示，刷新、手动下载、更新、看板、设置和退出操作保持原有行为。曲线保持固定高度和行内悬停详情，不增加滚动区域。

实现位于 `MenuBarPopoverView.swift`，复用现有 `TokenCompositionView` 的紧凑模式，不改变数据查询或统计口径。
