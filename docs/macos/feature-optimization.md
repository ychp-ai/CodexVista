# 用量日历与趋势悬浮卡优化

日期：2026-09-16。

原悬浮卡直接展开所有模型，卡片高度随模型数量增长；趋势提示随最近曲线切换为模型用量，难以快速查看总量。

现在日历与趋势共用 `DailyUsageHoverCard`，总 Token 使用大字号，保留四类 Token 和等值费用摘要。模型明细默认折叠，点击展开后保持卡片显示，支持滚动阅读；收起后恢复悬浮关闭行为。趋势按鼠标横向位置选择日期，高亮并锚定该日期最高的可见节点，忽略鼠标纵向距离；总量曲线隐藏时使用最高可见模型节点，卡片使用对应日期或周期的完整汇总数据。关闭卡片、切换月份或隐藏曲线会清理展开状态。

验证：项目脚本 `./script/build_and_run.sh --verify` 构建、启动并核实当前工作区 App 进程通过；`TokenFormatterTests` 与 `DashboardQueryServiceTests` 回归测试通过；`git diff --check` 通过。首次沙盒构建因 Swift 宏插件受限失败，允许沙盒外执行后通过。已查看运行中的趋势与日历页面；GUI 工具未能触发悬停，尚未实测卡片展开、收起和鼠标跨窗口移动。文档截图尚未重新导出，截图调用已适配新组件接口。

后续调整：趋势悬浮锚定改为横向最近日期的最高可见节点。定向回归测试通过，覆盖鼠标纵向移动、横向切换日期、隐藏总量、日期中点以及零值重合节点优先总量。
